# Documentation Folder Structure

Documentation is grouped by portfolio pipeline.

| Folder | Purpose |
|---|---|
| `shared/` | Cross-pipeline architecture, data dictionary, synthetic data, model diagrams, and governance notes. |
| `pipeline_a_synapse_baseline/` | ADF + Synapse baseline technical documentation. |
| `pipeline_b_databricks_qa/` | Databricks QA lakehouse documentation, testing, defects, UAT, and dashboard validation. |
| `pipeline_c_monthly_insights/` | Planned Analytics Officer reporting story, Synapse serverless views, Power BI semantic model, and monthly insights brief. |
