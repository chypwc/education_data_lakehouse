# Power BI Folder Structure

Power BI artefacts are grouped by portfolio pipeline.

| Folder | Purpose |
|---|---|
| `pipeline_a_synapse_baseline/` | Baseline Synapse Power BI report and screenshots. |
| `pipeline_b_databricks_qa/` | Databricks QA Power BI report and screenshots. |
| `pipeline_c_monthly_insights/` | Planned monthly insights dashboard and semantic model evidence. |

`report_notes.md` records overall Power BI notes across the portfolio.
